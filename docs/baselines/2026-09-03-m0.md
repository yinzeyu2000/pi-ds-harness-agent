## Golden behavior

`scripts/m0-golden-traces.ts` and `tests/golden/m0-agent-loop.json` lock these Pi semantics without credentials or network access:

1. pure conversation lifecycle;
2. one tool call followed by the final model response;
3. parallel multi-tool execution, where `tool_execution_end` follows actual completion (`fast`, then `slow`) while durable tool-result messages retain assistant source order (`slow`, then `fast`);
4. streaming start/deltas followed by an aborted terminal assistant message.

## Native Windows test baseline

The reproducible entry is `scripts/run-baseline-windows.ps1`. It creates an isolated temporary home, discovers the installed Git Bash, disables local-model and cloud-metadata discovery, runs the requested gates, restores the environment, and removes only its marker-owned temporary directory.

The isolated upstream full suite is green on this Windows host after correcting the platform defects exposed by the first run. POSIX-only assertions are capability-gated; equivalent Windows behaviors remain covered rather than being globally skipped.

Resolved platform groups:

- File-symlink tests now probe privilege support; directory-link coverage uses Windows junctions when appropriate.
- Git Bash selection rejects legacy WSL `bash.exe`, discovers installations beside `git.exe`, and tests working directories through Node's native path view.
- Unix-domain transport behavior is preserved on Unix; Windows maps the configured endpoint deterministically to a named pipe and covers lifecycle/address-collision behavior.
- External-editor settings are parsed into executable/argv without a shell, preserving quoted paths, backslashes, and spaces.
- Windows process-tree termination waits for `taskkill` and forcibly closes the direct shell so timeout/abort cannot hang on inherited pipes.
- Persisted package overrides and eval artifact references use portable `/` separators.
- Concurrent first-use installation of `fd`/`rg` is deduplicated, avoiding archive and binary races.
- The isolated runner reuses already verified cached native helpers and fixes its test credential isolation without enabling live provider suites.

The runner now provides a repeatable, network-independent Windows regression entry while keeping the home/config environment isolated.

## Canonical full-green gate

Linux remains the canonical Pi full-suite and first Secure Beta platform per ADR-011. This host has no ordinary WSL distribution, but Docker Desktop 4.65.0 provides a WSL2 Linux engine. Using the official `node:22-bookworm` image, Linux static/browser checks passed, as did the full Agent suite (418 passed, 1 skipped), full Server/Unix transport suite (50 passed, 2 skipped), eval artifact persistence, and focused coding-agent path/editor tests. The container ran as root and did not include system `fd`/`rg`, so POSIX permission and search-tool cases were not counted as a full Linux suite. `.github/workflows/m0-baseline.yml` remains the canonical Ubuntu full-green gate.

The Docker image is test infrastructure only. It is not required to run the Agent on Windows; Docker/WSL may later be selected as one optional Sandbox Provider behind the ExecutionBroker boundary.
